The `ritmo` skill's netcode playbook follows `@typeonce/ritmo-netcode`: a seat that leaves no longer ends the match. It says where the rule for a seat without a driver belongs (a system that reads the seats' `left` input, never host code), to pass on what the transport knows with `session.drop`, what `onFailure` now means, and that a page that comes back builds its session again. The proofs gain a match and a fuzzed run with seats that leave.
