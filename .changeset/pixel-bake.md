`ritmo-tools pixel bake` draws sprites from a model of 3D shapes (`<name>.bake.json`) through one camera and one light, set once in `pixel.config.json` under `bake`, so a set of buildings, vehicles, or props stays one set. A model can be boxes, cylinders, spheres, flat faces, and free meshes, in groups and repeats, with hand-placed pixels on top, and can turn to any number of headings and animate. It writes a clean PNG on the palette, a sprite source or a sheet, a preview, and on request a normal map from the real surfaces and a ground shadow. `pixel review` names the model as the art's source. The `ritmo-pixel-art` skill says when to use it.
