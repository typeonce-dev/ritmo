Two games run below on the packages you install: the rules headless, the
page only a host. Click one to start it, and bring a friend or a gamepad.

<Game id="town" ratio="3 / 2" />

## Town

A Game Boy-style overworld: walk tile by tile, read the signs, talk to the
villagers, alone or with a friend who joins on WASD or a gamepad
([local multiplayer](/features/multiplayer/)). The rules are headless
systems with a `Mode` state machine (`Exploring` / `Talking`). Art: the CC0
[Ninja Adventure](https://pixel-boy.itch.io/ninja-adventure-asset-pack) pack
by Pixel-boy and AAA.

## Top-down

Five parts to find. The rules are
[`integration/top-down`](https://github.com/typeonce-dev/ritmo/tree/main/integration/top-down),
the same schedules its headless tests run.

## Games built with Ritmo

**[Spirit Call](https://spirit-call.typeonce.dev)**: a top-down action game
for the phone, with teams of elemental spirits, rendered in 3D with Three.js
and shipped to Android and iOS.
[Play it](https://spirit-call.typeonce.dev) or read
[its source](https://github.com/SandroMaglione/spirit-call).

**[Inkline Town](https://github.com/SandroMaglione/inkline-town)**: a town
simulation in isometric line art, rendered with Three.js.

**[Grand Theft Auto: Lunigiana](https://gta-lunigiana.fedemas.dev)**: an
open-world car-theft game in isometric pixel art, set in the real valleys of
Lunigiana on a map built from survey data, rendered with Three.js.
[Play it](https://gta-lunigiana.fedemas.dev) or read
[its source](https://github.com/mastro993/gta-lunigiana).
