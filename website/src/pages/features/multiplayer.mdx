Two players on one keyboard, more on gamepads, one screen. Each player
joins by pressing a button on a free device, and your game reads each one
on their own.

<Game id="town" ratio="3 / 2" />

Walk with the arrows. For a second player, press any key on WASD or any
button on a gamepad, and they appear next to you. Q (or Ⓑ) leaves.

<Claim title="A press on a free device joins, and does nothing else">

Your game names its slots. A device nobody holds joins the first free slot
when someone presses a button on it, and that press is spent on joining,
so joining never also jumps. Keyboard halves and pads pool together:

```ts twoslash title="players.ts"
import { Controls, Gamepad, Keyboard } from "@typeonce/ritmo-browser"
// ---cut---
const Actions = Controls.actions({
  buttons: ["talk", "back"],
  vectors: ["move"]
})

// [!code highlight:5]
const Players = Controls.players(Actions, {
  slots: ["p1", "p2"],
  join: "any",
  leave: "back"
})

const wasd = {
  move: Keyboard.vector({ up: ["w"], down: ["s"], left: ["a"], right: ["d"] }),
  talk: [" "],
  back: ["q"]
} as const

const arrows = {
  move: Keyboard.vector({
    up: ["ArrowUp"],
    down: ["ArrowDown"],
    left: ["ArrowLeft"],
    right: ["ArrowRight"]
  }),
  talk: ["Enter"],
  back: ["Backspace"]
} as const

const pad = {
  move: Gamepad.vector({ stick: "left" }),
  talk: ["south"],
  back: ["east"]
} as const

const players = Players.pool({
  // Two players on one keyboard
  left: Keyboard.actions(window, wasd),
  right: Keyboard.actions(window, arrows),

  // Every pad on its own
  pads: Gamepad.pads(window, pad, 4)
})
```

</Claim>

<Claim title="Each player has their own input, and hears when someone arrives">

Every slot reports its own actions, the device it holds, and an event when
someone joins or leaves.

```ts twoslash title="players.ts"
import { Controls, Gamepad, Keyboard } from "@typeonce/ritmo-browser"
const Actions = Controls.actions({ buttons: ["talk", "back"], vectors: ["move"] })
const Players = Controls.players(Actions, { slots: ["p1", "p2"], join: "any", leave: "back" })
const wasd = { move: Keyboard.vector({ up: ["w"], down: ["s"], left: ["a"], right: ["d"] }), talk: [" "], back: ["q"] } as const
const arrows = { move: Keyboard.vector({ up: ["ArrowUp"], down: ["ArrowDown"], left: ["ArrowLeft"], right: ["ArrowRight"] }), talk: ["Enter"], back: ["Backspace"] } as const
const pad = { move: Gamepad.vector({ stick: "left" }), talk: ["south"], back: ["east"] } as const
const players = Players.pool({ left: Keyboard.actions(window, wasd), right: Keyboard.actions(window, arrows), pads: Gamepad.pads(window, pad, 4) })
declare const input: ReturnType<typeof players.snapshot>
declare const spawnSecondPlayer: () => void
// ---cut---
// In a system: input = resources.input.get()
if (input.p2.event === "joined") {
  spawnSecondPlayer()
}

const walk = input.p2.vectors.move

if (input.p2.joined && input.p2.device === "pads") {
  // false while the pad is unplugged: the seat is kept
  const connected = input.p2.connected
}
```

</Claim>

<Claim title="A third player in a two-player game does not compile">

The slots are in the type, so a slot the game does not have is an error,
not an `undefined` at run time.

```ts twoslash title="players.ts"
import { Controls, Gamepad, Keyboard } from "@typeonce/ritmo-browser"
const Actions = Controls.actions({ buttons: ["talk", "back"], vectors: ["move"] })
const Players = Controls.players(Actions, { slots: ["p1", "p2"], join: "any", leave: "back" })
const pad = { move: Gamepad.vector({ stick: "left" }), talk: ["south"], back: ["east"] } as const
const players = Players.pool({ pads: Gamepad.pads(window, pad, 4) })
declare const input: ReturnType<typeof players.snapshot>
// ---cut---
// @errors: 2339
input.p3.actions.talk
```

</Claim>

<Claim title="An unplugged pad keeps its seat">

The player is back the moment the pad reconnects. The rest of the room is
handled by calls on the pool, from the host:

- **Joining** is open when the game says so (`setJoining`): always for
  drop-in play, or only on a join screen. A pause menu frees a slot with
  `leave("p2")`.
- **Seats from the start.** A player who is in before anyone presses
  anything is seated by the game: `seat("p1", "right")`, or the first pad
  with `seat("p1", { pads: 0 })`. A taken seat comes back as a reason,
  not a crash.
- **Touch and [rebinding](/features/rebinding/)** work as they do for one
  player: on a phone, the town seats player one on on-screen buttons.

</Claim>

<Claim title="The whole room replays as one input">

The pool is one source: one `snapshot()` reads every pooled device and
decides the joins across them. Declared with `InputCapture.SourceOf`, as
for one player, a [replay](/features/replays/) or the fuzzer provides the
whole room at once.

```ts twoslash title="input.ts"
import { Controls, Gamepad, Keyboard } from "@typeonce/ritmo-browser"
const Actions = Controls.actions({ buttons: ["talk", "back"], vectors: ["move"] })
const Players = Controls.players(Actions, { slots: ["p1", "p2"], join: "any", leave: "back" })
const pad = { move: Gamepad.vector({ stick: "left" }), talk: ["south"], back: ["east"] } as const
const players = Players.pool({ pads: Gamepad.pads(window, pad, 4) })
// ---cut---
import { Descriptor } from "@typeonce/ritmo"
import { InputCapture } from "@typeonce/ritmo-browser"

const PlayersInput = Descriptor.Service<
  InputCapture.SourceOf<typeof players> // [!code highlight]
>()("Game/Players")
```

Every part of it is tested headless with scripted keyboards and pads
(`Gamepad.scriptedPads`), with no controller in reach.

</Claim>
