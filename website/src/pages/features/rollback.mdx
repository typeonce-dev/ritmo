Online, the other player's input always arrives late. Waiting for it makes
every press lag; guessing it and fixing the guess later is rollback.

<Game id="netcode" ratio="16 / 9" />

Two bots play one match, each on its own peer, over a network whose latency
rises every few seconds. Watch the strips: outlined ticks ran on a guess, lit
ones ran again after a wrong guess, and the green line is where both peers
checked their worlds and found them the same.

<Claim title="Your input never waits for the network">

Each peer guesses the input it does not have yet and plays on. When the real
input turns out different, it rewinds to that tick and runs forward again,
within one frame. Play seat 0 yourself, and raise the latency in the corner:

</Claim>

<Claim title="Peers agree, or say which tick">

Every 30 ticks the peers compare a checksum of a tick all real input has
reached. A mismatch is reported as `Desynced` on its tick, and every peer is
resynced from seat 0's world. Peer B at the end of the match above: its
checksums agree with peer A's up to tick 570, after 48 rollbacks.

```text title="session.status(), peer B"
{
  epoch: 1,
  tick: 598,
  confirmed: 587,
  verified: 570,
  again: 278,
  rollbacks: 48,
  dropped: 0,
  ahead: -0.2593099905661802,
  inputDelay: 2,
  delayChanges: 0,
  roundTripMS: [ 408.6436663522086, 0 ],
  hidden: [ false, false ]
}
```

A [sync test](/features/bugs/#rollback-checked-on-every-tick) finds a desync
in a test run instead, on the tick it starts.

</Claim>

<Claim title="The simulation never sees the network">

It reads every seat's input for the tick from one source, and the session
fills it before each tick. Offline play, tests, and online matches run the
same systems. Input from other peers is decoded with the game's own schema
(Effect here, any Standard Schema works).

```ts twoslash title="input.ts"
import { Descriptor, Schema } from "@typeonce/ritmo"
import { Schema as S } from "effect"
const codec = <T extends S.Top & { readonly DecodingServices: never; readonly EncodingServices: never }>(schema: T) => {
  const json = S.toCodecJson(schema)
  return { "~standard": S.toStandardSchemaV1(json)["~standard"], "~encode": S.toStandardSchemaV1(S.flip(json)) }
}
import { InputCapture } from "@typeonce/ritmo-browser"
import { Netcode } from "@typeonce/ritmo-netcode"
const PlayerInput = S.Struct({ dx: S.Literals([-1, 0, 1]), fire: S.Boolean })
type PlayerInput = typeof PlayerInput.Type
const Inputs =
  Descriptor.TransientResource<InputCapture.SnapshotOf<typeof Seats>>()(
    "Game/Inputs"
  )
const Game = Schema.bind(Schema.fragment({ resources: { Inputs } }))
// ---cut---
// Every seat's input for the tick being run
const Seats = Descriptor.Service<Netcode.Source<PlayerInput>>()("Game/Seats") // [!code highlight]

// Two seats; input from another peer is decoded with the schema
const seats = Netcode.seats(codec(PlayerInput), {
  count: 2,
  idle: { dx: 0, fire: false }
})
if (!seats.ok) throw new Error(seats.error.reason)

const runtime = Game.Runtime.make({
  services: Game.Runtime.services(
    Game.Runtime.service(Seats, seats.value.source) // [!code highlight]
  ),
  resources: { Inputs: [] }
}).value
```

`InputCapture.system` copies the source into `Inputs` each tick, so systems
read it like any captured input.

</Claim>

<Claim title="Any transport, on a connection you open">

Ritmo runs no server and opens no connection. A link wraps one your game
opened: `WebSocketNetworkLink` for a relay, `WebRtcNetworkLink` for a data
channel between peers, or your own `send`, `receive`, and `status`.

```ts twoslash title="session.ts"
import { Clock, Descriptor, Schema } from "@typeonce/ritmo"
import { BrowserHostClock, InputCapture } from "@typeonce/ritmo-browser"
import { Netcode, WebSocketNetworkLink } from "@typeonce/ritmo-netcode"
interface PlayerInput { readonly dx: number; readonly fire: boolean }
const Seats = Descriptor.Service<Netcode.Source<PlayerInput>>()("Game/Seats")
const Inputs = Descriptor.TransientResource<InputCapture.SnapshotOf<typeof Seats>>()("Game/Inputs")
const Game = Schema.bind(Schema.fragment({ resources: { Inputs } }))
const Capture = InputCapture.system(Game, { name: "Game/Capture", source: Seats, resource: Inputs })
const simulate = Game.Schedule(Capture)
declare const seats: Netcode.Seats<PlayerInput>
const runtime = Game.Runtime.make({ services: Game.Runtime.services(Game.Runtime.service(Seats, seats.source)), resources: { Inputs: [] } }).value
const step = Clock.hz(60)
// ---cut---
// A socket the game opened, to a relay between the peers
const socket = new WebSocket("wss://relay.example.com/match/42")

const session = Netcode.rollback(runtime, {
  simulate,
  seats,
  seat: 1, // seat 0 hosts: every peer starts from its world
  links: [WebSocketNetworkLink.make(socket)], // [!code highlight]
  hostClock: BrowserHostClock.make(window),
  step
})
```

Each input is for a tick slightly ahead (2 by default): too short to feel,
long enough to arrive in time. `adaptiveDelay` follows the round trip.

</Claim>

<Claim title="One call per step drives the match">

Each step of the fixed-step loop, the session reads the network, rolls back
if a guess was wrong, ticks, and sends this peer's input. Rendering runs
outside the simulation, so it sees a rollback as ordinary changes.

```ts twoslash title="loop.ts"
import { Clock, FixedLoop } from "@typeonce/ritmo"
import { BrowserTickSource } from "@typeonce/ritmo-browser"
import type { Netcode } from "@typeonce/ritmo-netcode"
interface PlayerInput { readonly dx: number; readonly fire: boolean }
declare const session: Netcode.Session<PlayerInput, never>
declare const readInput: () => PlayerInput
declare const draw: () => void
declare const showDisconnected: (failure: unknown) => void
const step = Clock.hz(60)
// ---cut---
FixedLoop.start({
  source: BrowserTickSource.make(window),
  step,
  maxFrameSeconds: 0.25,
  maxStepsPerFrame: 5,
  rate: session.rate, // slows this peer while it runs ahead
  update: session.update({ // [!code highlight]
    input: readInput,
    // A desync is a bug in the game: log it. The session resyncs.
    onHalted: (error) => console.error(error)
  }),
  render: draw, // outside the simulation: never rolls back
  onFailure: showDisconnected // a peer left, or runs another version
})
```

</Claim>

<Claim title="What a rollback would break does not compile">

A rollback runs ticks again, so whatever they do runs again. State a system
keeps in `local` would not come back, and a service that is not input,
plain data, or rewindable (audio, say) would act twice. The session refuses
both.

```ts twoslash title="combo.ts"
import { Clock, Descriptor, HostClock, Schema } from "@typeonce/ritmo"
import { InputCapture } from "@typeonce/ritmo-browser"
import { Netcode, type NetworkLink } from "@typeonce/ritmo-netcode"
interface PlayerInput { readonly dx: number; readonly fire: boolean }
const Seats = Descriptor.Service<Netcode.Source<PlayerInput>>()("Game/Seats")
const Inputs = Descriptor.TransientResource<InputCapture.SnapshotOf<typeof Seats>>()("Game/Inputs")
const Game = Schema.bind(Schema.fragment({ resources: { Inputs } }))
const Capture = InputCapture.system(Game, { name: "Game/Capture", source: Seats, resource: Inputs })
declare const seats: Netcode.Seats<PlayerInput>
declare const link: NetworkLink.NetworkLink
const runtime = Game.Runtime.make({ services: Game.Runtime.services(Game.Runtime.service(Seats, seats.source)), resources: { Inputs: [] } }).value
const options = { seats, seat: 0, links: [link], hostClock: HostClock.standard, step: Clock.hz(60) }
// ---cut---
const Combo = Game.System(
  "Game/Combo",
  { local: () => ({ hits: 0 }) },
  ({ local }) => {
    local.hits++
  }
)

// @errors: 2375
Netcode.rollback(runtime, {
  ...options,
  simulate: Game.Schedule(Capture, Combo)
})
```

</Claim>

<Claim title="A physics engine rolls back with the game">

A physics engine keeps its own world, so a rollback would leave it ahead of
the game. Wrapped with `Checkpoint.rewindable`, it is saved at every
checkpoint and restored with every rollback.

```ts twoslash title="physics.ts"
import { Checkpoint, Descriptor, Result, Schema } from "@typeonce/ritmo"
declare class PhysicsWorld {
  step(): void
  takeSnapshot(): Uint8Array
  static restoreSnapshot(bytes: Uint8Array): PhysicsWorld | undefined
}
declare const world: PhysicsWorld
const Game = Schema.bind(Schema.fragment({}))
// ---cut---
const physics = Checkpoint.rewindable(world, {
  save: (world) => world.takeSnapshot(),
  restore: (bytes) => {
    const restored = PhysicsWorld.restoreSnapshot(bytes)
    return restored === undefined
      ? Result.failure({ _tag: "CorruptSnapshot" as const })
      : Result.success(restored)
  }
})
const Physics = Descriptor.Service<typeof physics>()("Game/Physics")

const Step = Game.System(
  "Game/Step",
  { services: { physics: Game.System.service(Physics) } },
  ({ services }) => {
    services.physics.current.step()
  }
)
```

Checksums see only the world, so copy what gameplay reads from the engine
(positions, contacts) into components each tick. That is what peers
compare, and what a resync restores.

</Claim>

<Claim title="Sounds play once, even when a tick runs twice">

A tick run again publishes its events again. The session hands the host
each event in three streams: `predicted` while its tick may change,
`withdrawn` for ticks a rollback undid, and `confirmed` once it cannot.

```ts twoslash title="sounds.ts"
import { Descriptor } from "@typeonce/ritmo"
import type { Netcode } from "@typeonce/ritmo-netcode"
const Hit = Descriptor.Event<{ readonly kind: "body" | "shield"; readonly x: number }>()("Game/Hit")
declare const session: Netcode.Session<unknown, never, typeof Hit>
declare const sounds: { readonly play: (kind: "body" | "shield") => void }
declare const particles: { readonly burst: (tick: number, x: number) => void; readonly cancel: (tick: number) => void }
// ---cut---
const hits = session.events(Hit)

// Every frame, after the session advanced:
for (const { tick } of hits.withdrawn()) particles.cancel(tick)
for (const { tick, value } of hits.predicted()) {
  particles.burst(tick, value.x) // at once, cancelled if undone
}
for (const { value } of hits.confirmed()) {
  sounds.play(value.kind) // exactly once
}
```

</Claim>

<Claim title="A hidden tab does not end the match">

A browser stops a hidden tab, so that peer goes silent. Given the tab's
visibility, the session tells the others the moment it hides. They wait for
it (`"stall"`), or play on with idle input and resync it when it comes back
(`"resync-on-return"`).

```ts twoslash title="hidden.ts"
import { Clock, Descriptor, Schema } from "@typeonce/ritmo"
import { BrowserHostClock, BrowserVisibility, InputCapture } from "@typeonce/ritmo-browser"
import { Netcode, WebSocketNetworkLink } from "@typeonce/ritmo-netcode"
interface PlayerInput { readonly dx: number; readonly fire: boolean }
const Seats = Descriptor.Service<Netcode.Source<PlayerInput>>()("Game/Seats")
const Inputs = Descriptor.TransientResource<InputCapture.SnapshotOf<typeof Seats>>()("Game/Inputs")
const Game = Schema.bind(Schema.fragment({ resources: { Inputs } }))
const Capture = InputCapture.system(Game, { name: "Game/Capture", source: Seats, resource: Inputs })
const simulate = Game.Schedule(Capture)
declare const seats: Netcode.Seats<PlayerInput>
const runtime = Game.Runtime.make({ services: Game.Runtime.services(Game.Runtime.service(Seats, seats.source)), resources: { Inputs: [] } }).value
const step = Clock.hz(60)
declare const socket: WebSocket
declare const names: ReadonlyArray<string>
// ---cut---
const session = Netcode.rollback(runtime, {
  simulate,
  seats,
  seat: 1,
  links: [WebSocketNetworkLink.make(socket)],
  hostClock: BrowserHostClock.make(window),
  step,
  hidden: { // [!code highlight]
    visibility: BrowserVisibility.make(document), // [!code highlight]
    // A tab closed while hidden still ends the match, 30 s + timeoutMS later
    afterMS: 30_000,
    then: "resync-on-return" // [!code highlight]
  } // [!code highlight]
})
if (!session.ok) throw new Error(session.error.reason)

// In the HUD: who everyone is waiting for
const away = session.value
  .status()
  .hidden.flatMap((hidden, seat) => (hidden ? [names[seat]] : []))
```

</Claim>

For a turn-based game, `Netcode.lockstep` takes the same options and waits
for every seat's input instead of guessing. Matches hold across machines
because the game is the [same everywhere](/features/determinism/).
